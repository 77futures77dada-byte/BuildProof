# Разбор внешней критики по пунктам

Источник: `docs/design-inputs/external-critique-landing-2026-11-25.md`. Дата разбора: 2026-11-26. Автор: бизнес-архитектор (этап 1).

Правила разбора:
- Отклонять без причины нельзя.
- Не выдумываем кейсы, число клиентов, отзывы, фото.
- «Уже 7 объектов» пишем, только если это правда.
- Гарантию и реквизиты решает владелец.
- Запрещённое слово из `design-brief.md` §1 не используем, в том числе в пересказе критики: пишем «фактический».

Колонка «Где»: **app PR** — этот редизайн приложения; **landing PR** — отдельная правка лендинга; **ждёт владельца**.
Ссылки вида `01 §5.1` ведут в `docs/design/01-business-flow.md`.
