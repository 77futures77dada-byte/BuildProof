### 2. Рабочий с аккаунтом не может отчитаться. Документ пишет обратное. HIGH
**Где:** §0 строка `/project/:id/stages` («gc, foreman, worker правят»), §3.4 шаги 3 и 5 («частично»), §4 строка «Сегодня».

Последняя версия этой функции (`001_security_and_profile_locale.sql:35`) отдаёт `forbidden` всем, кроме `gc` и `foreman`. Значит, единственная главная кнопка рабочего сегодня заканчивается ошибкой сервера. Это не «частично», это тупик. Через этот экран не придёт ни один отчёт рабочего, и активация невозможна даже для рабочего с паролем.
**Исправить:** в §3.4 и §6 записать новый конфликт K14: «отчёт рабочего через UI отклоняется сервером». В §8 поставить его выше всех экранных решений: экран отчёта рабочего переводится на `submit_stage_report` (фото + % одним вызовом, уже есть). Пока этого нет, рабочему кнопку % не показывать, оставить только фото (`PhotoUploadForm`, загрузка рабочему разрешена).
