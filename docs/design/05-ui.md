## 2. Шрифт и шкала

Onest variable (`public/fonts/onest/`, 3 woff2 = 78 072 Б + OFL), `font-display: swap`, preload latin + cyrillic (49 620 Б), latin-ext по `unicode-range`. Запасные с метриками: «Onest Fallback Roboto» / «Onest Fallback Arial» (`size-adjust` и `*-override` из 02 §7.3). Стек: `--font-sans` (`font-sans`), моно — `--font-mono` (только иллюстрации лендинга).

- База: `body` 17 / 400 / 1.4 (было 500; замечание владельца 2026-11-28 «слишком жирно»). Зона рабочего `[data-zone="field"]`: 18 / 500 / 1.4, поля `max(18px, 1em)`; вне зоны поля ≥ 17 px (`max(17px, 1em)`). `input, button, select, textarea { font: inherit }`.
- Вес 400 — текст владельца (зона `app`); в зоне рабочего запрещён линтером (там база 500).
- Числа-значения ≥ 500, крупные цифры 600. `tabular-nums` / `.num-col` — только столбцы, даты, время.
- `text-xs`, `text-sm`, `text-[<17px]` в коде приложения запрещены (поднятые до 17 px значения в `@theme` — страховка, не разрешение). `text-base` запрещён в зоне рабочего.

## 4. Тема

- Одна тема на весь продукт: лендинг, вход, все вкладки, листы, модалки, рабочий, заказчик. Токены на `:root`; тёмная — по `prefers-color-scheme: dark`, если нет `<html data-theme="light">`; `data-theme="dark"` включает тёмную принудительно. Других переключателей (`data-skin-dark`, `.bp-native` для цвета экрана) нет.
- Один корень темы: `<div id="bp-root" data-zone="landing|app|field">` (`ThemeRoot` в `App.tsx`). `field` — `/project/:id/today` и `/review`; корень `WorkerProjectCard` тоже ставит `data-zone="field"`.
- **Правило корня для модалок:** `Modal` и `Sheet` рендерят портал в `#bp-root` (`portalTarget()`), не в `document.body`, и наследуют тему и `data-zone` экрана. Оверлей — `--scrim`. Фокус — внутрь, ловушка Tab, возврат на кнопку-источник; Esc и «Закрыть» ≥ 48 px, кроме `busy-locked`.
- `theme-color` в `index.html` дублирует `--bg` (мета не читает CSS-переменные; исключение в allowlist).
- 3D-модель (`src/features/house3d`) и анимация лендинга (`SiteLoop`) — иллюстрации с фиксированной палитрой, исключения с причиной в `scripts/check-tokens.allow.json`.

## 6. Правила `check-tokens` (строгие с этого шага)

Исключения — `scripts/check-tokens.allow.json` с причиной; поле `kinds` сужает исключение; `temporary` — временное. `--no-allow` показывает, что осталось мигрировать.

## Миграция

Шаг «Основа» убрал `app-skin.css`. Пока экраны не переписаны, `src/styles/legacy-bridge.css` (временный, без сырых цветов) перекрашивает стоковую палитру Tailwind на токенах внутри `#bp-root` и держит старые классы `bp-*`. **Последний экранный шаг удаляет этот файл и его `@import` в `src/index.css`, а также атрибут `data-skin-dark` и класс `bp`.**

Временные записи allowlist (`"temporary"`, `kinds: palette, small, weight`); экранный агент убирает записи своей группы и заменяет классы на токенные (`bg-surface`, `text-fg`, `border-line`, …). В итоговом PR временных записей — 0. Осталось 509 нарушений (`palette` 382, `small` 125, `weight` 2).
