## 2. Шрифт и шкала

**Inter variable** (`public/fonts/inter/`: cyrillic, latin, latin-ext woff2 из `@fontsource-variable/inter@5.3.0` + OFL), `font-display: swap`, preload latin + cyrillic, latin-ext по `unicode-range` (эстонские š, ž). Запасной с метриками: «Inter Fallback» (Arial / Roboto, `size-adjust: 107.12%`). Onest убран (2026-11-28, владелец: «широкий и тяжёлый»). Стек: `--font-sans` (`font-sans`), моно — `--font-mono` (только иллюстрации лендинга). Все цифры — `tabular-nums` (на `body`).

**Максимальный вес — 500 везде** (приложение, лендинг, вход, SVG). Иерархия строится размером и цветом, не весом. Проверяется дважды: `check-tokens` правило `heavy` (код) и `check-overflow` `heavy_text` (вычисленный вес видимого текста в DOM).

- База: `body` 17 / 400 / 1.4. Зона рабочего `[data-zone="field"]`: 18 / 500 / 1.4 (тонкий шрифт на солнце не читается — `weight`-правило линтера; 500 не превышает максимум), поля `max(18px, 1em)`. `b, strong, th` — 500. `input, button, select, textarea { font: inherit }`.
- Телефон: текст ≥ 17 px. Десктоп: 17 px основной текст и кнопки, 16 px — только `lg:text-meta`. `check-overflow --strict-a11y` меряет 17 px ниже 1024 и 16 px от 1024.
- `text-xs`, `text-sm`, `text-[<17px]` в коде приложения запрещены. `text-base` запрещён в зоне рабочего.

## 4. Тема

- Одна тема на весь продукт: лендинг, вход, все вкладки, листы, модалки, рабочий, заказчик. Токены на `:root`; тёмная — по `prefers-color-scheme: dark`, если нет `<html data-theme="light">`; `data-theme="dark"` включает тёмную принудительно. Других переключателей (`data-skin-dark`, `.bp-native` для цвета экрана) нет.
- Один корень темы: `<div id="bp-root" data-zone="landing|app|field">` (`ThemeRoot` в `App.tsx`). `field` — `/project/:id/today` и `/review`; корень `WorkerProjectCard` тоже ставит `data-zone="field"`.
- **Правило корня для модалок:** `Modal` и `Sheet` рендерят портал в `#bp-root` (`portalTarget()`), не в `document.body`, и наследуют тему и `data-zone` экрана. Оверлей — `--scrim`. Фокус — внутрь, ловушка Tab, возврат на кнопку-источник; Esc и «Закрыть» ≥ 48 px, кроме `busy-locked`.
- `theme-color` в `index.html` дублирует `--bg` (мета не читает CSS-переменные; исключение в allowlist).
- 3D-модель (`src/features/house3d`): цвета — токены `--house-*` (одинаковые в обеих темах, navy-сцена); анимация лендинга (`SiteLoop`) — иллюстрация с фиксированной палитрой, исключение с причиной в `scripts/check-tokens.allow.json`.

## 6. Правила `check-tokens` (строгие с этого шага)

`heavy` (вес > 500 где угодно: `font-semibold`/`bold`/…, CSS `font-weight` 600–900/`bold`, SVG `font-weight`), `hex`, `colorfn`, `font` (кроме `var(--font-*)`/`inherit`), `palette` (классы стоковой палитры), `small` (`text-xs`/`text-sm`/`text-[<17px]`, `text-meta` без `lg:`/`xl:` и CSS < 17 px в коде приложения; лендинг `src/features/landing/` — вне правила до своего PR), `weight` (зона рабочего: `src/pages/Today.tsx`, `src/pages/Review.tsx`, `src/components/WorkerProjectCard.tsx`, `src/components/report/**`, `src/components/ui/**`, и CSS-правила `[data-zone="field"] …`: вес 400/normal/lighter, `font-normal`/`font-light`/`font-thin`, `text-base`, < 17 px), `base` (`font: inherit` у контролов в `tokens.css`). Исключения — `scripts/check-tokens.allow.json` с причиной; поле `kinds` сужает исключение; `temporary` — временное. `--no-allow` показывает, что осталось мигрировать.

- Колонки 4/4/4 при 1024–1279 px, 4/5/3 с 1280 px; панель всегда 4/12 = 33 %.
- Порядок DOM = видимый = порядок Tab (слева направо, сверху вниз); CSS `order` не используется.
- 3D в режиме `compact`: заголовок только для чтения с экрана, «Проиграть стройку» в строке «Завершено этапов», чипы этапов (легенда цвета и выбор с клавиатуры) одной прокручиваемой строкой, легенда состояний без пояснений.

## Миграция

Шаг «Основа» убрал `app-skin.css`. Пока экраны не переписаны, `src/styles/legacy-bridge.css` (временный, без сырых цветов) перекрашивает стоковую палитру Tailwind на токенах внутри `#bp-root` и держит старые классы `bp-*`. **Последний экранный шаг удаляет этот файл и его `@import` в `src/index.css`, а также атрибут `data-skin-dark` и класс `bp`.**
