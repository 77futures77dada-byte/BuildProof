BuildProof — тест шрифтов (шорт-лист: Manrope, Onest, Geologica)

Ширина колонки ≈ 390 px (телефон). Размеры 17 / 20 / 28 px, веса 400 и 600. Строки «○ ✓» берутся из системного шрифта: в латинских/кириллических subset-файлах этих символов нет (см. 02-type.md). Блок «блик» — грубая имитация солнца на экране (contrast 0.55).
