# 02 — Шрифт (Исследователь; r1 2026-11-25, r2 и r3 2026-11-26 по аудитам этапа 2)

## Итог r3
- **Фаворит: Onest.** **Запасной: Geologica.** Оба variable, ось wght.
- **По данным это ничья** [М2r-6]. Onest остаётся фаворитом по правилу «при равенстве», по двум признакам, проверенным при весах рабочего (500 и 600, не 400):
  1. x-height выше на 5 % при том же px (§3).
  2. Эстонские строки уже. В 334 px при 18 px: у Onest 9 строк на 7 фраз, у Geologica 10. Без переноса Onest уже на 3.6 % (§4).
- **Окончательно решает уличный тест на телефоне** (§5.2) — **ждёт владельца**, срок — до слияния PR лендинга. Если владелец выберет B, меняем на Geologica. Файлы и CSS запасного готовы (§7).
- Plex исключён по решению владельца.

Метки: [Б2r-n] — «Бригадир» r2, [М2r-n] — «Март» r2, [И2r-n] — «Инвестор» r2, номер = пункт аудита.

Чем проверено:
- fontTools 4.69.1 во временной папке: таблицы `cmap`, `GSUB`, `hmtx`, `OS/2`, `hhea`, `fvar`, `MVAR`, инстансы через `varLib.instancer`.
- Рендер: `type-test/index.html` в Chromium 1243. Ширины, строки и контраст считает сама страница (`window.__typeTest`).

- Цена своего шрифта — 48.5 КБ на русской странице.

Если владелец решит, что 0 КБ важнее, `system-ui` допустим. Это его решение.

## 5. Оценка и решение

### 5.1 Баллы (0–5, вес в скобках, максимум 50)
| Критерий | Onest | Geologica | system-ui | Manrope |
|---|---|---|---|---|
| Улица: x-height и штрих при 500/600 (×3) | 4 | 4 | 3 | 3 |
| Различимость 1/l/I, 0/O, 3/8, 6/9 (×2) | 3 | 3 | 3 | 2 |
| Табличные цифры (×1) | 5 | 4 | 4 | 4 |
| Вес ≤ 120 КБ (×1) | 4 | 5 | 5 | 5 |
| Характер (×2) | 4 | 4 | 3 | 2 |
| Ширина ET в 334 px при 500/600 (×1) | 4 | 3 | 5 | 5 |
| **Итого** | **39** | **38** | **35** | **31** |

**Вывод: ничья по данным** [М2r-6].
- Одно очко — в пределах субъективной оценки.
- Отклонение запасного шрифта у обоих в пределах цели ≤ 4 %, поэтому как довод не используется.
- Onest — фаворит при равенстве: выше x-height и меньше переносов ET при 500/600 (§4).
- Geologica темнее при равном весе и на 14 КБ легче.
- Решает уличный тест.

### 5.2 Уличный тест — ждёт владельца [М2r-7]
| | |
|---|---|
| Кто | владелец. Бригадир — по желанию, второй голос |

| Условия | улица, день, яркость — авто, телефон на вытянутой руке, без приближения |

| Правило | B → меняем на Geologica. A или «одинаково» → остаётся Onest. Если тест сделан на Android, заодно в DevTools сверяют, что подменный шрифт Roboto стоит без сдвига |
| Срок | до слияния PR лендинга. Нет ответа к сроку — остаётся Onest, запись в «ждёт владельца» |

## 6. Роли, размеры, контраст

### 6.1 Роль → px / вес / line-height / tnum [Б2r-5, Б2r-9]
Общие правила:
- `line-height` везде без единиц.
- Числа — вес ≥ 600 везде, включая время.
- tnum — только столбцы, даты, время и счётчики в строке. Крупные одиночные числа и коды — без tnum.
- На маршрутах рабочего и бригадира вес 400 запрещён.

| Элемент (рабочий и бригадир, если не сказано иное) | px | вес | line-height | tnum | цвет и прочее |

### 7.2 Загрузка [Б2r-3, М2r-12]
- **Preload на всех маршрутах:** latin + cyrillic, 49 620 Б. Статично в `index.html`, без JS.
- **latin-ext:** грузится сам по `unicode-range`, когда на странице появляются `š ž Š Ž` и подобные буквы. Preload не делаем.
- **`font-display: swap` везде.** Идея `optional` для рабочего снята.

**Цена решения, честно.** При первом заходе на эстонскую страницу буквы `š ž` рисуются подогнанным запасным шрифтом, пока не придёт latin-ext (28 КБ). Потом происходит замена. Ширина у них совпадает в пределах ≤ 4 % (§4), кнопки держит `min-height`. Эстонец получает лишние 15.9 КБ кириллицы. `õ ä ö ü` лежат в latin и приходят сразу.

```html
<link rel="preload" href="/fonts/onest/onest-latin-wght-normal.woff2" as="font" type="font/woff2" crossorigin>
<link rel="preload" href="/fonts/onest/onest-cyrillic-wght-normal.woff2" as="font" type="font/woff2" crossorigin>
```

## 8. Символы, которые нельзя писать текстом; значки [Б2r-6, Б2r-11]
Проверено по `cmap`: этих знаков нет ни в Onest, ни в Geologica.

| Знак | Код | Замена |
|---|---|---|
| ○ | U+25CB | SVG `pending` |
| ● | U+25CF | SVG по шкале свежести |
| ✓ ✔ | U+2713, U+2714 | SVG `ok` (галочка в залитом круге) — только «Проверено» |
| ✗ ✘ ✕ | U+2717, U+2718, U+2715 | SVG `rejected` |
| → ← | U+2192, U+2190 | SVG-стрелка |
| ⚠ ★ ▲ ▼ | U+26A0, U+2605, U+25B2, U+25BC | SVG |
| U+202F | узкий неразрывный пробел | U+00A0. Время — в 24-часовом формате |
| U+2009 (нет у Geologica) | тонкий пробел | U+00A0 |

Разрешены: `· • … – — « » „ “ ” € № ° × −`, U+00A0.

Набор `<StatusIcon kind>`. Все формы различимы в одном цвете: см. блок «Значки в одном цвете» в тесте.
- **Статусы отчёта:** `pending` (кольцо), `ok` (галочка в залитом круге), `rejected` (крест в круге), `stale` (треугольник).
- **Состояния отправки — отдельный набор:** `sending` (часы), `sent` (стрелка вверх из лотка), `unsent` (стрелка вниз в лоток).

Галочка `ok` никогда не означает «отправлено».

**Проверка строк.** Regex прогоняется по `src/**/*.{ts,tsx,json}`, а не только по i18n, как шаг `run-checks`:
```js
/[\u2190\u2192\u25B2\u25BC\u25CB\u25CF\u2605\u26A0\u2713\u2714\u2715\u2717\u2718\u202F\u2009]/u
```
