# Claude Code: переписать лендинг по критике (запускать после редизайна приложения, на той же теме и шрифте)

Ветка `claude/landing-v2` от свежего `origin/main`. Используй токены и шрифт из `src/styles/tokens.css` (после `claude/app-redesign`). Читай `docs/design-inputs/external-critique-landing-2026-11-25.md` и `buildproof-decisions.md`.

## Что сделать (по приоритету критики)
1. **H1 и подзаголовок на язык боли и результата.** Базовый вариант: «Перестаньте звонить прорабам. Видите все объекты и реальный прогресс с фото, без ежедневных отчётов в WhatsApp.» Проверь слово «реальный» по правилам контента проекта: если запрещено, замени на «фактический». Сделай 2 запасных варианта в `docs/design/landing-h1-variants.md` (из критики).
2. **Убрать самообесценивание.** Строку «Новый продукт, без громких обещаний» удалить с первого экрана; честность остаётся в блоке «Что проверяем и чего не обещаем» ниже.
3. **Блок «Чем лучше WhatsApp» выше FAQ**: таблица было/стало (фото теряются, проценты никто не считает, нет истории) против единого журнала с историей и проверкой скачков > 25.
4. **Блок «Первый день»**: зарегистрировались → отправили ссылку прорабу → рабочий отправил фото → вечером видите отчёт. Без выдуманных минут: только то, что реально работает. Снимает страх «рабочие не будут пользоваться».
5. **CTA:** «Начать: 30 дней бесплатно» оставить; «Посмотреть пример» заменить на «Посмотреть объект за 30 секунд» и вести на демо.
6. **Блок про основателя** (имя, фото, 3 предложения) сделать как компонент, который показывает данные из `src/config/legal.ts`/`founder.ts`. Если данных нет, блок **не рендерится** (никаких плейсхолдеров на странице).
7. **Индикатор «когда закончим при таком темпе»** показать в мок-дашборде только как диапазон и только если формула из `buildproof-decisions.md` это допускает; без обещаний точной даты.
8. Мобильная версия глазами владельца с телефона: касания ≥ 48 px, шрифт ≥ 17 px.

## Жёстко
- Не выдумывать клиентов, отзывы, цифры, фото, гарантии. Всё, чего нет, идёт в список «ждёт владельца» в PR: имя и фото, реквизиты, телефон, реальные цифры, гарантия возврата, скриншоты чатов «до».
- Плейсхолдеры в видимом тексте не публиковать. Если данных нет, блок скрыт.
- Тексты на RU, EN, ET (ET с пометкой `TODO native ET review`), без английских слов в RU.
- Агент-контролёр «Март» проходит страницу сверху вниз и пишет возражения HIGH/MED/LOW; пока есть HIGH, PR не готов. «В целом хорошо» писать нельзя.
