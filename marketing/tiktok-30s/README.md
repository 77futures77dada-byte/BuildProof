# BuildProof · пиксель-арт реклама для TikTok, 30 секунд

Вертикальный ролик 1080×1920, 30 fps, ровно 30,0 с, H.264 MP4. Без закадрового
голоса: всё понятно без звука, субтитры вшиты.

| Версия | Файл | Статус текста |
| --- | --- | --- |
| RU | `out/buildproof-tiktok-30s-ru.mp4` | исходная |
| EN | `out/buildproof-tiktok-30s-en.mp4` | перевод с RU |
| ET | `out/buildproof-tiktok-30s-et.mp4` | **TODO native ET review**: не публиковать до проверки носителем |

Ключевые кадры (0, 3, 7, 11, 15, 20, 23, 26, 29,5 с) лежат в `frames/<язык>/`.

## Пересборка

Нужны Node 20+ и `ffmpeg`/`ffprobe` в PATH. Из корня репозитория:

```bash
npm --prefix marketing/tiktok-30s run render:ad          # все три языка
npm --prefix marketing/tiktok-30s run render:ad -- ru    # только один
```

Скрипт `scripts/render.mjs` по порядку:

1. `build-texts.mjs` собирает `text.*.json` в `src/texts.gen.js` и останавливает
   сборку, если в тексте есть символ, которого нет в шрифтах, или запрещённая
   формулировка (геолокация, «ИИ», «реальное», Telegram/SMS и т. д.).
2. `make-audio.mjs` синтезирует музыку и эффекты в `assets/audio/*.wav`.
3. HyperFrames (`npx hyperframes@0.9.38 render`) рендерит MP4 для каждого языка.
4. `ffprobe` проверяет результат: H.264, 1080×1920, 30 fps, 900 кадров, 30,0 с, ≤ 50 МБ.
5. `ffmpeg` вынимает ключевые кадры в `frames/`.

Предпросмотр в браузере: `npm --prefix marketing/tiktok-30s run dev`.
Проверка композиции: `npm --prefix marketing/tiktok-30s run check`.

## Как устроено

- `index.html` — композиция HyperFrames: один canvas 270×480, показанный ровно ×4
  (`image-rendering: pixelated`), и две звуковые дорожки.
- `src/timeline.js` — все времена сцен и событий. Его читают и картинка, и звук,
  поэтому касание и щелчок не расходятся.
- `src/engine.js` — пиксельный движок: только целые координаты и 16 цветов палитры,
  без прозрачности и сглаживания (затемнения сделаны дизерингом).
- `src/scenes.js` — девять сцен. Кадр есть функция времени `t`: таймеров нет,
  любой кадр рисуется независимо. Для стороннего захвата есть `window.__setT(t)`.
- Персонажи, телефоны и экраны нарисованы кодом, не сгенерированы моделью.

Язык задаётся переменной композиции `lang` (`ru` / `en` / `et`), для предпросмотра
ещё и параметром `?lang=et`. `?safe=1` рисует рамку безопасной зоны TikTok
(160 px сверху, 380 px снизу, 120 px справа).

## Тексты

Все надписи лежат в `text.ru.json`, `text.en.json`, `text.et.json`. После правки
запустите `npm run render:ad`. Длинные строки переносятся сами, но новый текст
стоит проверить по кадрам в `frames/`.

**Адрес сайта.** В `src/config/legal.ts` адреса сайта нет, поэтому в финале стоит
`<<ADDRESS>>`. Замените `final.site` в трёх файлах и пересоберите; сборка
напоминает об этом предупреждением.

## Шрифты

- Заголовки и субтитры: **Press Start 2P** (OFL), 8 px логических = 32 px в кадре.
- Интерфейс: **Departure Mono** (OFL), 11 px логических = 44 px в кадре.

В брифе для интерфейса указан VT323, но в нём нет кириллицы: русский текст уходил
в запасной шрифт с засечками. Departure Mono близок по характеру и покрывает
кириллицу и эстонские буквы. Наличие каждого символа в обоих шрифтах проверяется
при сборке по таблице `cmap`.

## Звук

Музыка и эффекты синтезированы скриптом `scripts/make-audio.mjs`, чужих треков и
сэмплов нет. 120 BPM, все смены сцен стоят на долях; на 2,5 с настроение меняется
с вопроса (ля минор, без ударных) на ответ (до мажор, с ударными). Эффекты:
щелчок на касаниях, вспышка, «пинг» на ✓, тихий двойной писк на красной карточке.

Измерено `ffmpeg ebur128`, на слух не проверялось: музыка −18 LUFS, итоговый микс
около −14,8 LUFS, пик −2,4 dBFS.

Если нужен трек из библиотеки TikTok: загрузите ролик, убавьте исходный звук до
нуля или оставьте только эффекты (для этого уберите `<audio id="music">` из
`index.html` и пересоберите) и подберите в Commercial Music Library чиптюн
110–120 BPM. При 120 BPM смены сцен попадут в доли без подгонки.
